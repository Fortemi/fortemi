# v2026.7.17 Release Announcement

Fortemi v2026.7.17 is the corrective publication for v2026.7.16. It preserves
the same Knowledge Shard contracts, exact `2.0.0/full-v1` evidence, supported
platform cells, and receipt-bound consumer revisions.

## Fixed

- Linux arm64 sidecar builds now use a run-scoped Colima profile whose state,
  cache, and temporary files live on mutsu's `/Volumes/build` volume.
- The build no longer waits on cleanup of the obsolete home-volume profile.
- Post-build profile deletion is bounded to 60 seconds so stale VM state
  cannot hold the dedicated `titan` coordinator indefinitely.
- Mutsu host identity remains bound to the exact pinned Ed25519 fingerprint,
  with three bounded 15-second acquisition attempts.

## Compatibility Boundary

The evidence remains limited to the Fortemi authority-to-React/core-to-HotM
contract surface on Linux x86_64, Linux arm64, and native macOS arm64 in run
6393. Windows remains deferred to issue #1096, and issue #1081 remains
`NO-GO` pending independent audit.
