# Fortémi 2026.10.11

Note profile similarity now keeps roots and candidates within the selected tenant archive. Hidden and deleted notes and ineligible embedding sets remain excluded. Imported profile vectors can participate without auxiliary embedding-set memberships.

fortemi-login scopes saved sessions to the complete issuer URL and client ID, refuses mismatched legacy sessions, and requires explicit opt-in for plaintext file fallback.

Builds reuse compatible Cargo state with ownership checks, stable CI identity and bounded retention. Docker compiler caches separate image families and architectures, including hosted builds. Compiler reuse requires compatible builder storage to survive; removing a temporary builder leaves its next compilation cold. Docker-only CI jobs no longer allocate unused host Cargo entries, and ordinary tests avoid unconsumed coverage instrumentation.

This release changes no database migration, protocol or shard schema. Existing named-profile compatibility limits remain in effect.
