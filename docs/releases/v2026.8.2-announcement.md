# v2026.8.2 Release Announcement

Fortemi v2026.8.2 is the corrective publication for v2026.8.1. The v2026.8.1
release chain passed tag authority, builder, test-database, and Knowledge Shard
conformance checks, then stopped at the documentation-shard freshness gate.
The committed support shard and its receipt still identified the v2026.8.0
producer, so application images and release assets were not published.

v2026.8.2 regenerates the bundled Fortemi documentation shard from the exact
v2026.8.2 producer. Its receipt binds the producer version and image reference
to the committed shard digest and byte length. The freshness verifier checks
those fields against the workspace version before publication proceeds.

## Application and contract scope

The application changes remain those documented for v2026.8.1: deterministic
archive lifecycle DDL, bundle backup and PKE hardening, the attachment
extraction-strategy migration, typed SNN retention-safety results, and
release-only container publication. The canonical OpenAPI schema and forward
migration set are unchanged by this corrective patch.

Knowledge Shard compatibility remains limited to the exact schema, profile,
producer, consumer, fixture, and receipt cells in the suite contract registry.
The regenerated support shard is a `core-v1` producer artifact; it does not
change or broaden the Knowledge Shard application contract.

## Publication behavior

Ordinary branch and main pushes continue to validate without publishing
container versions. The signed v2026.8.2 CalVer tag starts the release build.
Use v2026.8.2 rather than the incomplete v2026.8.1 publication for application
images, native assets, and the support-shard receipt.

## Upgrade

```bash
docker compose -f docker-compose.bundle.yml pull
docker compose -f docker-compose.bundle.yml up -d
```

The database migration and rollback guidance is unchanged from v2026.8.1.
Back up the database before upgrading, and restore to a separate destination if
rollback is required.
