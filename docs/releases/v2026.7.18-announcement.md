# v2026.7.18 Release Announcement

Fortemi v2026.7.18 is the corrective publication for v2026.7.17. It preserves
the same Knowledge Shard contracts, exact `2.0.0/full-v1` evidence, supported
platform cells, and receipt-bound consumer revisions.

## Fixed

- Both mutsu coordinator jobs now require noninteractive public-key
  authentication.
- Password and keyboard-interactive fallback are disabled, so a missing or
  revoked CI authorization fails within the bounded connection timeout instead
  of holding the `titan` runner's controlling terminal.
- Linux arm64 builds retain their run-scoped Colima profiles and bounded
  teardown on `/Volumes/build`.

## Compatibility Boundary

The evidence remains limited to the Fortemi authority-to-React/core-to-HotM
contract surface on Linux x86_64, Linux arm64, and native macOS arm64 in run
6393. Windows remains deferred to issue #1096, and issue #1081 remains
`NO-GO` pending independent audit.
