# v2026.7.15 Release Announcement

Fortemi v2026.7.15 is the corrective publication for v2026.7.14. It preserves
the same Knowledge Shard contracts, exact `2.0.0/full-v1` evidence, supported
platform cells, and receipt-bound consumer revisions.

## Fixed

- Native Linux arm64 and macOS sidecar coordinator jobs now run on the
  dedicated `titan` host runner, whose network route to mutsu is part of the
  release environment.
- Linux arm64 Colima state, cache, and temporary files remain on mutsu's
  `/Volumes/build` volume rather than its constrained home volume.

## Compatibility Boundary

The evidence remains limited to the Fortemi authority-to-React/core-to-HotM
contract surface on Linux x86_64, Linux arm64, and native macOS arm64 in run
6393. Windows remains deferred to issue #1096, and issue #1081 remains
`NO-GO` pending independent audit.
