# Fortémi 2026.10.10

2026.10.10 fixes hosted embedding-set authorization and tenant-scoped reads
that prevented existing-vector loaders from using their selected archive (#1278).

## What changed since 2026.10.9

Authorization now resolves the outer embedding-set slug or UUID using the verified
request tenant and selected archive. Set reads, member deletion, and vector-run
lookup/list operations reuse the request-bound tenant connection, retaining the
PostgreSQL tenant setting throughout those operations.

The patch also records seven existing closed route templates explicitly and
checks that future parameterized routes have a backing lookup or a documented
closure. Follow-ups #1279 and #1280 track those separate capabilities.

## Upgrade and verification boundaries

This patch adds no database or shard-schema migration. Scoped local verification
passed 11 hosted database/HTTP checks, 29 route-policy checks, and 10 normalizer
checks, including tenant/archive isolation and unchanged denial behavior.

Exact-source CI, release validation, documentation checks, signed publication,
and immutable image receipts remain required by the release procedure. These
focused checks do not establish suite parity or browser acceptance. Suite NO-GO
and W01a acceptance boundaries remain in force.
