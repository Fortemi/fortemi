# Fortémi 2026.9.7

Hosted deployments can now configure additional CA certificates for their identity provider. Set `FORTEMI_AUTH_CA_BUNDLE` to a readable PEM bundle mounted into the API container. The verifier uses these certificates alongside public roots for OIDC discovery and JWKS requests. Invalid configured bundles stop startup with a configuration error. Restart the API after updating the bundle.

TLS certificate and hostname verification remain enabled. This release consumes fortemi-auth v2026.9.0 and includes the hosted verifier in standard image builds. Activating hosted mode still requires its documented key-provider, quota and database-isolation setup. Full live token and tenant qualification remains tracked in itops #662/#663; transport verification alone does not establish those results.

See the authentication guide for file mounts, trust rotation and deployment prerequisites.
