# Fortemi 2026.9.11

This release publishes the dataset execution validation `1.0.1` authority
declaration for the independent `@fortemi/react` consumer implemented at signed
commit `6718e9f930193a12b8aed27b61ebf9c47871ac44`.

The declaration closes the producer metadata portion of Fortemi #1131 and links
the consumer work in Fortemi React #412. The authority manifest digest is
refreshed to bind the declaration. The release does not change dataset wire
schemas, canonical serialization, positive or negative vectors, execution
behavior, database migrations, REST/AsyncAPI contracts, or dependencies.

The producer contract verifier covers all 11 manifest files and the positive,
degradation, schema, capability, resource, tamper, and producer receipt vectors.
React's built and published package must still be qualified independently against
the released authority and a bounded server fixture. Actual service liveness,
hosted authorization, operator usability, and human accessibility evaluation are
separate acceptance gates.

This remains an alpha live remote persistence boundary. Static AIWG indexing,
Knowledge Shard state transfer, and live Fortemi persistence stay separate. No
`core-v1`, `full-v1`, or `record-v1` claim changes. The suite audit remains
`NO-GO`; only the named producer contract and alpha live-persistence boundary
are in scope.

Related: [Fortemi #1131](https://git.integrolabs.net/Fortemi/fortemi/issues/1131),
[React #412](https://git.integrolabs.net/Fortemi/fortemi-react/issues/412), and
[React PR #472](https://git.integrolabs.net/Fortemi/fortemi-react/pulls/472).
