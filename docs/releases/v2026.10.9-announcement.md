# Fortémi 2026.10.9

2026.10.9 corrects Docker network creation in the suite platform runner on
Mutsu's Bash 3.2 (#1273). It supersedes 2026.10.8 while preserving that release's
immutable tag and published assets.

## What changed since 2026.10.8

The network helper builds a nonempty argument array containing the required
bridge driver before appending an optional CI ownership label. Unset and empty
ownership scopes no longer trigger an unbound-array error under strict mode.
Populated scopes retain their ownership label, and bounded collision retries,
subnet verification and cleanup behavior remain unchanged.

Focused mock tests pass on Mutsu's Bash 3.2.57 and Titan's Bash 5.3.9, including
unset, empty and populated scopes and the five existing network behaviors.

## Upgrade and verification boundaries

This correction introduces no runtime API, shard-schema or data migration.
Genuine documentation seed generation, exact-source release validation, signed
publication and supported-platform acceptance remain required. Focused helper
tests do not establish suite parity. Suite NO-GO and W01a acceptance boundaries
remain in force.
