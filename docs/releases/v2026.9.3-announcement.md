# v2026.9.3 Release Announcement

Fortemi v2026.9.3 is the corrective publication of the bounded, versioned MCP
dataset execution surface prepared in v2026.9.2. The earlier candidate failed
the isolated-container AsyncAPI byte-for-byte gate before images, binaries, or
a release entry were published. This release regenerates every AsyncAPI
artifact from the exact v2026.9.3 runtime and keeps the dataset contract itself
unchanged.

The core `manage_dataset_execution` tool supports versioned capability
discovery, fail-closed preview, UUID-scoped atomic execution, status,
checkpoint, cancel, exact-content resume/retry, detached receipt verification,
and bounded namespace-scoped archive. Its strict request and `RunReceipt`
schemas, canonical JSON/SHA-256 rules, fixtures, lifecycle vectors, and
independent verifier remain under `contracts/dataset-execution/1.0.0`.

The release qualifies only the alpha `live-remote-persistence` dataset profile.
It does not establish full suite parity, complete backup, universal
portability, or Knowledge Shard `core-v1`, `record-v1`, or `full-v1`
compatibility. Broader qualification work remains deferred and separately
tracked.

Use the signed `v2026.9.3` tag and published checksums. Callers should discover
the descriptor, preview the plan, require the exact advertised limits and
profiles, and retain the redacted receipt for replay and audit evidence.

References: ADR-107, Fortemi #1128-#1131, and roctinam/aiwg #2242.
