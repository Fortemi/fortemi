# v2026.7.19 Release Announcement

Fortemi v2026.7.19 is the corrective publication for v2026.7.18. It preserves
the Knowledge Shard format, exact `2.0.0/full-v1` evidence, supported platform
cells, and pinned consumer revisions.

## Fixed

- Mutsu sidecar jobs now derive the pinned CI public key from the
  Vault-managed private key and persist it in a root-owned OpenSSH path that is
  available before console login.
- Both mutsu publication paths validate the expected key fingerprint and
  effective sshd configuration before building Linux arm64 or macOS arm64
  artifacts.
- The supported-platform workflow now checks free space and inodes before both
  `matric-builder` jobs.
- The Linux arm64 contract container now reaches its isolated PostgreSQL
  service over a private Docker network and no longer receives the mutsu
  Colima daemon socket.

Windows remains the only deferred platform under Fortemi issue #1096. The
suite-wide audit remains `NO-GO`; this release does not make an unqualified
parity, complete-backup, or portability claim.
