# v2026.7.22 Release Announcement

Fortemi v2026.7.22 is the corrective publication for v2026.7.21. It includes
the same bounded background-job execution and redaction-safe diagnostic
improvements, with the tracked AsyncAPI snapshot and documentation Knowledge
Shard regenerated against the matching application version.

## Fixed

- Every job handler is bounded by `JOB_TIMEOUT_SECS` and converges through
  finite delayed retries to completion or terminal failure.
- Panics and abnormal task termination are contained with stable redacted
  reason codes; panic payloads and note content are never logged or persisted.
- Startup and periodic multi-worker-safe recovery prevent stranded `running`
  jobs, using a stale threshold derived from the effective runtime timeout.
- `FORTEMI_DIAGNOSTIC_PROFILE=jobs` provides targeted JSON stage telemetry;
  explicit logging variables retain override precedence.
- The tracked AsyncAPI snapshot now matches the release application version.
- `h2` 0.4.16 resolves `RUSTSEC-2026-0258`.

## Upgrade

```bash
docker compose -f docker-compose.bundle.yml pull
docker compose -f docker-compose.bundle.yml up -d
```

No schema migration, queue reset, or destructive database operation is
required. After upgrade, reproduce one note that previously remained in
`running` and confirm it completes or reaches a bounded retry/failure state.
Keep any diagnostic capture private and never post it publicly.
