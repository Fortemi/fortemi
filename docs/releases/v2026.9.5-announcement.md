# v2026.9.5 Release Announcement

Fortemi v2026.9.5 corrects shared-database test isolation in the release pipeline
and the bulk-reprocessing fixture cleanup protocol (#1142).

Integration and coverage test cases now run serially against their shared test
database. Hosted-role validation inspects the complete archive catalog, so
separate test mutexes cannot isolate unrelated schema changes or child processes.
All assertions and concurrency exercised inside individual tests remain active.
Bulk fixture cleanup uses the archive repository transaction and advisory lock.

The v2026.9.4 tag remains immutable. Its container images and release entries
were published, but coverage failed before native binaries were published.
This patch is the recovery candidate; its configured CI and publication checks
must pass before release completion is declared.

The dataset scope remains alpha `live-remote-persistence`. This maintenance
change adds no live load qualification, full-suite parity, complete-backup or
universal-portability claim, and no new Knowledge Shard profile guarantee.
