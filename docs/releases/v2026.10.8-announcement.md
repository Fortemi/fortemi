# Fortémi 2026.10.8

2026.10.8 corrects the suite platform runner's test-target selection (#1271).
It supersedes 2026.10.7 without rewriting that release's immutable tag.

## What changed since 2026.10.7

The suite runner asks Cargo to discover all unit and integration tests declared
by the pinned authority revision. Historical authorities no longer receive a
request for a newer, nonexistent archive-isolation test target. Current
authorities still execute their archive-isolation tests. Shared-database test
execution remains serial, and authority and consumer pins remain unchanged.

## Upgrade and verification boundaries

This correction introduces no runtime API, shard-schema, or data migration.
Release validation, genuine documentation seed generation, signed publication,
and supported-platform acceptance remain required; preparation is not proof
that those gates passed. Suite NO-GO and W01a acceptance boundaries remain in
force. Publication alone does not establish current-release suite parity.
