# fortemi-monthly-report

Project-local extension. Authors Fortémi's monthly report as a public blog post on
the docs site — a user-facing narrative of what shipped that month, published to the
Pagenary `posts` collection at `docs/content/posts/{YYYY-MM}-fortemi.md`.

- **Skill:** `skills/fortemi-monthly-report/SKILL.md`
- **Invoke:** `/fortemi-monthly-report <YYYY-MM> [--dry-run]` (native), or via discovery
  (`aiwg discover "fortemi monthly report"`).

Companion to the `fortemi-roadmap` extension.
